# 5090 闭环对照 → PPO 单轮验收

用户 2026-10-20 明确要求先用集群 5090 做不更新权重的闭环对照，确认适配后再跑一轮小规模 PPO。本目录是独立的新实验；不续跑旧诊断、不修改原 checkpoint。

- `share-space`，`computing-cluster-5090-01g`，1 张 Spot 5090，单作业 6 小时硬上限。
- 使用原始比赛 evaluator、原始机器人配置与全分辨率相机；两套策略都预测 32 步、执行 16 步。
- `turning_on_radio` 301、302，seed=0，每回合最多 3224 控制步。原始 JAX 和适配 Torch 各执行一次，每个回合用相同 NumPy 初始噪声序列。
- 留存固定间隔的 JAX 轨迹观测，以相同观测/噪声检查 Torch 动作与 greedy 子任务。动作误差按 checkpoint 的动作标准差归一化。
- 准入标准在提交前冻结于 `plan.json`：至少 8 个探针、子任务一致、每探针平均动作误差 ≤0.005/最大误差 ≤0.05、初态误差 ≤1e-4、逐实例 score 差 ≤0.1 且成功/失败结果一致。任何失败都禁止 PPO。
- 准入后，使用独立训练实例 1，采样最多 256 控制步；复用 RLinf 的 Flow-SDE、GAE、PPO 损失和 log-prob 规约，做一个 epoch。microbatch=1，累积 4 个 chunk，动作学习率 1e-6，value 学习率 1e-4。
- 第一轮验证单进程训练，不包含 Ray/FSDP 调度验收。保存真实 reward、梯度、冻结参数校验、更新参数及 optimizer。它不用于证明成功率提高。

上传范围：本实验脚本、适配源码、固定 RLinf 源码、新增 Python 依赖和已转换权重；复用现有 AFS 上的仿真、数据、原始权重。上传至用户现有私有桶 `260010165/behavior1k/rlinf-adapter-20261020/b1k-rlinf-1020-smoke01/`。签名 URL 仅存活于提交进程和作业启动命令，不写入本地回执。
